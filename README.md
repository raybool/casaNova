# CasaNova — Лендинг агентства элитной недвижимости

Полностью готовый проект лендинга для агентства элитной недвижимости CasaNova, построенный на Next.js 15 с использованием TypeScript и SCSS modules.

## Технологии

- **Next.js 15** (App Router, SSR/ISR)
- **TypeScript**
- **SCSS Modules** (*.module.scss) + global.scss
- **next/image** для оптимизации изображений
- **next/font** для оптимизации шрифтов
- Без UI-библиотек — только собственные компоненты

## Структура проекта

```
src/
├── app/
│   ├── layout.tsx          # Общий layout с шрифтами
│   ├── page.tsx             # Главная страница
│   └── api/
│       └── contact/
│           └── route.ts     # API endpoint для формы
├── components/              # Все компоненты
│   ├── Header/
│   ├── Hero/
│   ├── About/
│   ├── Advantages/
│   ├── Properties/
│   ├── Services/
│   ├── Testimonials/
│   ├── ContactForm/
│   └── Footer/
└── styles/
    └── global.scss          # Глобальные стили и переменные
```

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Особенности

### Дизайн
- Темный премиальный стиль с золотыми акцентами
- Адаптивный дизайн для всех устройств
- Плавные анимации при скролле (IntersectionObserver)
- Эффект "стеклянных" блоков с blur

### Производительность
- ISR с revalidate = 60 секунд
- Оптимизация изображений через next/image
- Оптимизация шрифтов через next/font
- Минимальный JavaScript на клиенте
- Цель: Lighthouse 90+, LCP < 1.8s

### Компоненты

1. **Header** — фиксированный хедер с плавной прокруткой по якорям
2. **Hero** — первый экран с фоновым изображением и CTA-кнопками
3. **About** — секция о компании с двухколоночным layout
4. **Advantages** — преимущества с иконками и анимациями
5. **Properties** — каталог объектов недвижимости (3 карточки)
6. **Services** — список услуг
7. **Testimonials** — отзывы клиентов
8. **ContactForm** — форма обратной связи с валидацией
9. **Footer** — футер с ссылками и копирайтом

### API

Форма контактов отправляет данные на `/api/contact`, который логирует данные в консоль и возвращает успешный ответ. В продакшене можно добавить отправку email или сохранение в БД.

## Изображения

В папке `public/` находятся заглушки изображений (SVG). В продакшене их нужно заменить на реальные фотографии:

- `hero-bg.jpg` — фоновое изображение для Hero
- `about-meeting.jpg` — фото деловой встречи
- `advantages-interior.jpg` — интерьер для секции преимуществ
- `property-1.jpg`, `property-2.jpg`, `property-3.jpg` — фото объектов недвижимости
- `services-villa.jpg` — фото виллы для секции услуг

## Кастомизация

### Цвета

Все цвета определены в `src/styles/global.scss` через CSS-переменные:

```scss
--color-bg-primary: #060608;
--color-bg-secondary: #0b0b0d;
--color-card: #141417;
--color-accent: #d5a75b;
```

### Шрифты

Используются шрифты из Google Fonts:
- **Заголовки**: Playfair Display
- **Текст**: Inter

Настроены в `src/app/layout.tsx` через `next/font`.
